# TypeScript for QA

Учебный проект для изучения TypeScript перед переходом к автоматизации тестирования с Playwright.

## Изученные темы

- Переменные и типы
- Интерфейсы
- Объекты
- Массивы
- Функции
- Методы filter, find, some и reduce

## Запуск примеров

```bash
npx tsx src/01-basics.ts
npx tsx src/02-products.ts
```

## Проверка типов

```bash
npx tsc --noEmit
```
